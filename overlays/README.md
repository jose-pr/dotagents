# The overlays moved

They live in [Boriken-Dev/agent-overlays](https://github.com/Boriken-Dev/agent-overlays), under `overlays/<name>/`.
Install one with:

```sh
dotagents overlays add <name> --repo "https://github.com/Boriken-Dev/agent-overlays.git@main#overlays"
```

This branch keeps the earlier history only.
